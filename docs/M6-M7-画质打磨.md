# M6 动态模糊 · M7 细节与画质打磨

## M6：时间轴上的快门

动态模糊不是给画面糊一层，而是「一帧的曝光时间覆盖一小段运动」，把这段运动平均掉。
本实现的取样点在合成时间轴上，所以和补帧共用同一条光流：

```
t 为当前合成帧相位；慢门在 t 附近取 N 个采样点
offset_j = (j - (N-1)/2) × 0.40 / 每对帧数
w_j      = max(0.08, 1 - |offset_j| / (half + 0.5))     // 三角权重
输出     = Σ w_j × synthesize(a, b, t + offset_j) / Σ w_j
```

- 三档：关闭 / 轻（3 采样）/ 强（5 采样）。
- 三角权重而不是等权：等权在运动边缘会出现「台阶」，三角权重更接近真实快门的连续曝光。
- 采样点都在光流 warp 后的中间帧上取，所以拖影沿运动方向，不会横向拉丝。
- 采样会增加合成次数：强档是每帧 5 次 warp，耗时约为关闭时的 3–5 倍。开启后 plan 会把
  输出上限压到 1440 长边 / 1.4MP，避免一单跑太久。

## M7：细节与锐度

缩放（尤其放大）之后画面天然偏软，M7 加了一道轻量 USM：

```
low  = 3×3 盒式均值
high = src - low
out  = src + high × amount          // amount 由 UI 滑杆 0…1 给出
```

实现上不写逐像素循环，而是把整式展开成一次 3×3 卷积交给 `vImageConvolve_ARGB8888`：

```
kernel 边缘 = -amount/9        中心 = (1 + amount) - amount/9        divisor = 256
```

纯 Swift 逐像素做 1080p 一帧要几百毫秒，会拖垮「快速放大」的实时感；vImage 走 SIMD，
同尺寸下是毫秒级。

- 默认 25%，20–40% 最自然；再高会在高对比边缘出现白边（halo）。
- 只在最终尺寸上做一次，不参与 AI 推理，不放大模型噪声。
- 与 Topaz 的 «Add Detail» 同类思路，但刻意做得保守：宁可欠一点，也不要假锐。

## M7：AI 输入的取法（画质分水岭）

旧做法是「先把原帧缩到目标÷4，再让模型放大 4×」，等于把原片细节先砍掉再重建。
现在的规则是：

```
aiEdge = min(2048, 原片长边)
若 4×aiEdge 的输出像素 > 24MP，则按 0.92 逐次缩到预算内
模型 4× 输出 → 高质量重采样到目标尺寸（多数情况是缩小）
```

也就是**超采样**：4× 重建的结果比目标还大，再缩下来。缩小时高频不丢，锐度和细节
比原来的「先缩小再放大」高一个档。代价是显存/内存与耗时，所以用 24MP 缓冲上限兜底，
plan 里也会提示「AI 输入长边 Npx、光推理约 X 分钟」。

## M7：抗闪烁

AI 逐帧超分对同一场景的不同帧会给出略有差异的高频细节，直接连起来看就是「沙沙」的抖动。
处理方式：

1. 用 `VNGenerateOpticalFlowRequest` 求上一帧到当前帧的位移场；
2. 把**上一帧已稳定的结果**按位移场 warp 到当前帧位置；
3. 以 0.22 的权重混入当前帧，位移越大（遮挡、切镜）权重越低，避免拖影。

只对 AI 模式开启（快速放大本身足够稳定），且混的是稳定后的上一帧，不会越混越糊。

## 与 Topaz 的差距（诚实版）

| 维度 | 本实现 | Topaz Video AI |
| --- | --- | --- |
| 超分模型 | Real-ESRGAN compact（x4v3，2 个权重） | 多种专用模型 + 逐场景权重 |
| 时序一致性 | 光流 warp + 0.22 融合 | 专门的时序模型（多帧输入） |
| 降噪 | 无独立降噪，靠模型隐式 | 独立降噪/去块/去隔行 |
| 运动补偿 | Vision 光流（Dense） | 自研光流 + 遮挡检测 |
| 平台 | iPhone，ANE/GPU 共享，无风扇 | 桌面独显 |

差距主要在「模型多帧输入」和「专用降噪」。iPhone 上跑 BasicVSR 级别的时序模型不现实，
所以选了「单帧模型 + 光流融合」这条能在手机上跑完的路。

## 真机验收清单

1. 同一段 5 秒 24fps 素材，分别用「快速 2×」「AI 2×」「AI 2× + 细节 40%」导出，对比锐度与噪点。
2. AI 模式看静止画面的噪点是否稳定（抗闪烁是否生效），尤其暗部。
3. 动态模糊三档分别导出同一段甩镜素材，检查拖影方向与长度。
4. 1080p 源导出 4K，检查 30 秒内是否因内存被杀（超采样缓冲最大约 96MB）。
